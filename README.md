# iamyigit Site

Personal website source and interface experiments. This repository contains the website project, not an AI-skill installer.

## Run locally

The checked-in project uses Next.js, React and TypeScript.

```sh
npm install
npm run dev
```

`npm run build` creates a production build; `npm start` serves a previously built app. Dependency versions and overrides are in `package.json`; this documentation update does not deploy or upgrade the app. Configure environment variables locally and never commit credentials.
